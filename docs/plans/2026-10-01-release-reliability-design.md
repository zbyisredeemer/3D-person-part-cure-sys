# v1.0.1 发布与运行可靠性

承接 v1.0.0 开源发布，优先降低首次运行门槛，并验证真实 HTTP 层。与界面重做和医学内容扩充相比，这些改动无需引入新的素材与医学结论，范围更适合维护版本。

## 交付

1. 修复畸形 URL 返回 500、JSON Content-Type 前缀误匹配，补齐 HTTP 方法声明与基础响应头。
2. 启动器通过子进程 IPC 确认自身服务就绪，并由操作系统分配测试端口，避免探测到其他进程而误报成功。
3. 真实 HTTP 回归覆盖静态资源、HEAD、错误输入、来源策略、请求大小及限流。
4. 生成只含构建产物、许可和运行说明的 tar.gz，附 SHA-256；不包含环境密钥、源码依赖或本机路径。
5. 解压包从任意工作目录启动，无需 npm install；CI 在干净临时目录验证实际发布包。

## 验收

现有测试及新增 HTTP 测试、Node.js 22/24、Docker、归档解压与生产冒烟全部通过，再发布 v1.0.1。保持 main 范围，其他工作区功能分支不合并。
