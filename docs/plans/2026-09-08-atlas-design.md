# 知体 Atlas 实现计划

目标：构建面向公众的中文交互式人体科普工作台，支持结构探索、症状演示、疾病与药物知识和有明确能力边界的健康问答。

架构：React + TypeScript + Vite；Three.js 场景与 UI 分离；经权威来源核对的静态内容独立管理。优先使用有明确来源与许可证的真实解剖网格。未配置 AI 服务时使用明确标记的本地科普演示，不伪装为在线模型。

视觉：蓝白色医学工作台；深蓝标题、浅灰蓝画布、细边框、低饱和器官色。左侧系统导航、中央三维人体、右侧器官档案；主要交互立即可见。

1. 建立 Vite/React 入口与基础样式，构建头部导航和探索工作台。
2. 并行准备独立器官网格、可旋转缩放的三维场景与授权说明。
3. 并行核对器官、疾病、药物和危险信号，编写独立风险判定与问答逻辑及测试。
4. 完成系统筛选、器官点选、透明皮肤、骨骼/血管/神经图层、视角、复位、局部聚焦和标签。
5. 实现症状区域动画、组合风险提醒、疾病和药物详情以及结构化科普问答。
6. 完成键盘操作、移动端布局、加载和失败状态；运行类型检查、生产构建、风险逻辑测试和交互验证。
7. 编写启动方法、内容来源、三维资产授权和精度限制，启动本地预览交付。

验收：所有按钮具有实际行为；器官目录覆盖用户指定结构；急症提示可触发且优先展示；无诊断、剂量、处方、治疗保证；不声称未审核模型为医学级。
