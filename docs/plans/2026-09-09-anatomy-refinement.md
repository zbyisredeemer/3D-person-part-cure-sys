# 人体模型细化与中性科普外观

本轮采用用户提出的「弱化性别器官」方案。保留现有真实器官网格，制作性别特征简化的皮肤衍生模型；不将男性原始解剖形变后标成女性模型。

1. 审查各图层实际网格名称，剔除外生殖器、完整男性尿道和生殖相关神经血管，保留肾脏、输尿管、膀胱、骨盆。
2. 对皮肤的局部性别特征进行连续曲面处理，保留原始文件和衍生说明，检查面数、有限坐标及非目标部位的几何一致性。
3. 改善自然器官配色、方向光和柔和阴影，减少全局过曝及选中色覆盖。
4. 提供全身、上半身、器官聚焦三种取景；默认上半身使器官细节更容易辨认。新增显示风格切换并保持图层与皮肤透明度可控。
5. 检查正面、背面、侧面、皮肤不透明度端点、可选系统图层、聚焦、标签和触屏表现。运行类型构建与有意义的显示过滤/模型完整性测试。

边界：外形是经过简化的科普展示，不用于性别或生殖系统教学；不改变内部器官原始几何，也不宣称新增临床精度。
