# 疾病目录与检索体验优化

疾病条目扩充后，原有目录在桌面端拉长页面，移动端横向排列也难以浏览。
本轮沿用现有视觉与医学内容，改进器官到疾病的查找路径。

- 疾病百科支持按器官筛选，和分类、搜索取交集；显示结果数与重置入口。
- 搜索支持关联器官的中英文名称、多个空白分隔词，保持原有名称与症状查询。
- 桌面疾病列表限制高度；移动端使用两列可滚动列表，长名称允许换行。
- 从器官档案进入疾病百科时，自动滚动目录以显示当前疾病；筛选后的详情保持当前可见选择。
- 器官搜索忽略首尾空白，收藏空状态区分“没有收藏”和“搜索未命中”，提供恢复入口。
- 收藏入口始终打开收藏列表，读取时去重并清理失效器官 ID。

验证：自动测试覆盖搜索、器官关联与组合筛选，运行完整测试及生产构建；浏览器检查桌面、窄屏与跨页面跳转；提交推送后重建 Docker 并执行健康和资源/API 冒烟检查。
