# Human Atlas 人体结构更新

接入固定版本 `ashemag/human-atlas@1c38bf35c254a891200d3cedecfd57abebe83d8d` 的 BodyParts3D 4.0 模型，保留当前中文器官目录、问答内容、图层开关与中性科普外观。

## 实现

- 导入 2,193 个原始结构，以 24 个器官/材质批次降低绘制调用；保留顶点、法线、拓扑和原始结构标识。模型按核心与可选图层分包。
- 用明确的结构名称规则修正上游分组中的脑室、肝实质分段、泪骨等错位。未被当前器官目录覆盖或被中性展示策略省略的 41 个结构列入清单。
- 参考资源缺少肺叶表面及完整周围神经，保留已有肺叶和脊髓/周围神经补充。保留已有中性皮肤。通过 BodyParts3D 坐标转换公式确认新数据与现有皮肤原点相差 13 mm，仅对新模型做整体平移。
- 从新几何计算标签锚点；维持原有拾取与聚焦。对向观察方向切换使用球面轨道插值，避免相机穿过器官并卡在最小距离。
- 模型 gzip 解码检查文件头，兼容静态服务器已自动解压的响应；卸载时取消下载，请求失败后清除缓存以支持重试。
- `manifest.json` 记录文件校验和、来源、结构数量与补充范围；保留 MIT 代码许可及 CC BY 4.0 模型署名，旧资产保持原有许可。

## 验证

测试覆盖器官分类、源结构唯一性、几何逐字节保真、有限坐标、合法索引及 gzip 解码。浏览器验证覆盖桌面/手机、器官聚焦、正背面、全部图层、旋转、拾取和非空画布。

完成结果：

- `npm test`：51 项通过；最后一轮针对模型/中性外观的 8 项回归通过。
- `npm run build`：类型检查和生产构建通过；`git diff --check` 无错误。
- Playwright：1440×1000、390×844、320×568 共 11 个场景截图及 WebGL 像素检查通过，12 个模型/解码器响应均成功，控制台无错误。验证了按需加载、心脏/肝脏/脑聚焦、全图层、拖动不误选、自动旋转和直接点击模型。
- 1024×768：模拟模型请求 503 后重新加载成功，保留单个画布，聚焦状态下正/背/左/右方向检查通过。
- 修复 320px 页面横向溢出，移动导航允许独立横向滚动；图层控件保持在模型区内。
- 截图和浏览器报告保存在未纳入 Git 的 `artifacts/human-atlas/`。浏览器检查使用桌面 Chrome 和模拟手机尺寸，未测物理触屏设备性能。
