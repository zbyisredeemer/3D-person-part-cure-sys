# 隐私与医学使用边界

本项目是人体结构与健康知识科普演示，未经过临床验证；不构成诊断、治疗、处方、分诊或专业医疗服务。模型是参考解剖结构，不能代表个体患者。知识库和危险信号规则覆盖有限，未触发提醒不代表安全。

## 数据流

| 数据 | 保存或发送位置 |
| --- | --- |
| 器官收藏 | 当前浏览器 localStorage，可取消收藏或清理站点数据 |
| 目录筛选、问答上下文 | 当前页面内存；刷新后清除，问答离开助手页面后清除 |
| 本地科普提问 | 前端或自托管 Node 服务处理，不发送给外部 AI |
| 在线 AI 提问 | 服务端向配置的提供商发送当前问题、上文及相关科普资料；`store: false` 不替代提供商的数据政策 |
| 命中危险信号的提问 | 本地优先处理，不调用外部模型 |
| 在线字体 | 如加载 Google Fonts，会向其服务发起网络请求；离线使用本机字体 |

应用没有账号系统、患者档案、数据库、广告追踪或问答持久化。基础设施提供商、反向代理和浏览器扩展的行为不在应用控制范围内。请不要输入姓名、证件号、联系方式、完整病历等可识别个人的信息。

自托管者应根据实际部署说明处理方、外部模型提供商、日志及数据保留方式；本文件描述仓库实现，不代替具体部署的隐私政策。
